MACRO HUB - Helldivers 2 stratagem macros
==========================================

Bind stratagems to keys or mouse buttons. Press the key in game and the hub
enters the stratagem code for you (holds Ctrl and presses the arrow keys).

BEFORE YOU START
1. Install AutoHotkey v2 (free): https://www.autohotkey.com/download/
   Pick the v2 installer. Macro Hub will offer to open this page if it
   cannot find AutoHotkey.
2. Make sure your in-game stratagem controls are: menu = Ctrl (hold),
   directions = arrow keys. (The menu key can be changed in the hub.)

RUN IT
Double-click MacroHub.exe. No install needed.
Windows may show "Windows protected your PC" because the exe is not signed.
Click "More info" then "Run anyway".

ADD A BINDING
1. Pick a stratagem in the list on the left (use Search to find it).
2. Click "Record keys", press a key (or several keys in order for a chain),
   then click "Stop recording". For mouse side buttons, pick one from the
   dropdown and click "Add mouse button".
3. Click "3. Add binding".

START THE MACROS
Click "Save, generate & run macros". The status at the bottom turns green.
Macros only work while the Helldivers 2 window is active.
Click "Stop macros" to turn them off (or right-click the green H tray icon > Exit).

RULES
- One trigger = one stratagem.
- Chains: buttons pressed in order, max 1 second between presses.
- A key used alone cannot also be part of a chain.
- Ctrl and the arrow keys cannot be triggers (the macro uses them).
- Trigger keys still do their normal in-game action too.

YOUR FILES
Profiles and the generated macros.ahk are saved in:
  Documents\MacroHub
Use "Save profile as..." / "Open profile..." to keep several loadouts.

IF THE GAME IGNORES THE KEYS
Close the hub, right-click MacroHub.exe > "Run as administrator", and start
the macros again.
